# dsh-exp-office

**DeepSeek Harness 的 Office / WPS 办公文件插件**：把 XLSX、DOCX、PPTX、PDF 的创建、读取、编辑、转换、校验与导出，交给 Agent 直接调用 —— **纯自研引擎、零运行时依赖、无网络访问**。

- **90 个工具**，覆盖四种格式 + 任务预览/执行/回滚五件套
- **字节级最小修改**：只改目标区间，图表、图片、宏、条件格式等部件逐字节不变
- **写入即事务**：文件锁 → 暂存 → 重新打开校验 → 原子替换，失败保留原文件
- **可信的验证**：12 个测试套件 719 项断言全绿，并用真实 Excel / Word / PowerPoint / WPS / Word 的 PDF 解析器交叉核对
- **能提取的文本才有用**：插件写出的 PDF 都带 `/ToUnicode`，第三方阅读器能读回内容

## 安装（一条命令）

```bash
dsh plugin --profile <你的 profile 名> add github:wanghenry9/dsh-exp-office
```

这条命令做三件事：把包从 GitHub 装进该 profile、把它注册成 profile 层（读取包内的 `dsh.bundle.patch`）、
装完即生效（下一次启动该 profile 就能用）。

```bash
# 升级到最新提交
dsh plugin --profile <profile> update dsh-exp-office

# 卸载
dsh plugin --profile <profile> remove dsh-exp-office
```

> 本地开发（改代码即时生效）：把依赖写成工作区目录，再用**复制**而不是包管理器同步到 profile 副本 ——
> 具体命令见 [docs/能力与验证.md](docs/能力与验证.md#安装--升级--卸载)。

## 快速开始

```text
# 1) 读一个区域（最省资源：只解析目标区域，不物化整张表）
office_read_range   { "path": "sales.xlsx", "sheet": "数据", "range": "A1:D20" }

# 2) 改单元格并保存（自动备份 + 写后重开校验）
office_write_cells  { "path": "sales.xlsx", "sheet": "数据",
                      "cells": [{ "ref": "B2", "value": 12800, "formula": "SUM(B3:B9)" }] }

# 3) 从零生成一份中文 PDF（自动嵌入字体子集，不需要模板）
office_create_pdf   { "path": "out/report.pdf",
                      "lines": ["季度销售报告", "", "本文件由插件直接生成。", "\f第二页"],
                      "title": "季度销售报告" }

# 4) 用真实 Office 重算公式（默认关闭，需插件配置 allowLocalAutomation: true）
office_recalculate  { "path": "sales.xlsx", "engine": "auto" }
```

路径都相对**工作区根目录**；所有工具返回统一信封（`success` / `request_id` / `output_file` / `warnings` / `changes` / `performance` / `data` / `error`）。

## 能做什么

| 格式 | 读取 | 写入 | 其它 |
|---|---|---|---|
| **XLSX / XLSM** | 工作簿结构、稀疏单元格、A1 区域、真实类型与安全标志 | 单元格（文本/数字/布尔/日期/公式）、样式、行列增删、合并、查找替换 | 表格对象、原生图表、CSV 导出、结构校验 |
| **DOCX** | 元数据、段落、表格、页眉页脚、批注、修订、全文 | 段落、样式、表格（建表/增删行/合并）、图片（含环绕）、书签、分页符、页面设置 | **文档比较**（段落级差异）、导出副本/纯文本、结构校验 |
| **PPTX** | 结构、幻灯片、版式与主题清单、全文 | 形状文本、增删排序、复制、文本框、图片、表格、原生图表、版式与主题切换 | **从零生成**演示文稿、导出 PDF、结构校验 |
| **PDF** | 元数据、页面、文本提取、全文搜索、表单、批注 | 旋转/删页/重排、水印与页码（**含中文**）、便签批注、表单填写、合并/拆分/重写 | **从零生成**（含中文与字体子集）、**表格提取**、图片提取、结构校验 |
| **跨格式** | 任意 Office 文档 → PDF（宿主内置引擎） | 本地 Office/WPS 联动：检测、重算、重渲染 | 任务五件套：预览 / 执行 / 回滚 / 查询 / 取消 |

完整工具清单（90 个，含参数与行为说明）见 **[docs/能力与验证.md](docs/能力与验证.md#支持范围逐格式能力)**。

## 怎么保证不把文件写坏

- **只改该改的字节**：XML 补丁式编辑，未触碰的部件逐字节不变（有专门的保真度套件盯着）
- **事务式写入**：同一文件加锁 → 写暂存 → **重新打开校验** → 原子替换；任何一步失败，原文件保持不变
- **该拒绝就拒绝**：加密文件、损坏结构、超限规模、越界参数都返回结构化错误码（`PASSWORD_REQUIRED` / `MEMORY_LIMIT` …）并给出下一步建议
- **不假装做到**：`validate_*` 会如实列出「需要渲染才能判定」的检查项（空白页、元素重叠、字体替换…），不返回一个假的「全部通过」
- **本地联动默认关闭**：驱动本机 Office/WPS 需要显式配置；禁宏、禁外链更新、禁弹窗、超时清理，且**只清理自己启动的进程**

## 已知限制

- **公式不重算**：写公式请同时给缓存值，或用 `office_recalculate`（需开启本地联动）让真实引擎重算
- **行列移位不重写公式引用**：只调行号与单元格引用，公式文本、合并区域、条件格式会返回警告
- **大文件**：读取按区域扫描（50 万单元格以内可读全表），但**写入**需要整表建索引 —— 单表 >30 万格默认拒绝（可配置）
- **不执行宏**：`.xlsm` / `.docm` 的 VBA 按原字节保留，从不执行
- **视觉无法自证**：版式是否变化、水印好不好看需要渲染成图片才能判定，本机没有光栅化器，因此不做视觉回归
- **明确不做**：XLSX 透视表修改与高级图表、PPTX 动画编辑、PDF 正向文本编辑 / OCR / 光栅化 / 转回 Office、图片环绕 `tight`/`through`、加密文件解密

其余边界（含每一条的原因）见 [docs/能力与验证.md](docs/能力与验证.md#已知限制)。

## 配置

插件配置（写在 profile 里，全部可选）：

| 配置 | 默认 | 说明 |
|---|---|---|
| `workspaceRoot` | 进程工作目录 | 允许读写的根目录，路径穿越会被拒绝 |
| `maxFileBytes` | 512 MB | 单文件大小上限 |
| `allowOverwriteOriginals` | `false` | 是否允许覆盖原文件（默认写回原文件但先备份） |
| `maxEditableCells` | 30 万 | 单张工作表可安全编辑的单元格上限 |
| `allowLocalAutomation` | **`false`** | 是否允许启动本机 Office/WPS 做重算 / 重渲染 |
| `automationTimeoutMs` | 120000 | 本地引擎单次调用超时（毫秒） |

## 验证

```bash
npm test                      # 12 个套件 / 719 项断言（含保真度、并发、本地联动）
npm run verify:excel          # 真实 Excel 打开插件输出并读数
npm run verify:word           # 真实 Word 打开并读数
npm run verify:pptx           # 真实 PowerPoint 打开并读数
npm run verify:automation     # 真实引擎重算：写错的公式缓存 999 → 重算成 3
npm run verify:pdf-cjk        # 中文 PDF：用 Word 的 PDF 解析器独立核对文本
npm run verify:privacy        # 推前隐私扫描（0 命中才提交）
```

验证口径是「**第三方能读出才算数**」：例如从零生成的中文 PDF，自家读取器读得出来不算完成，
要 Word 自带的 PDF 解析器也能读回中文正文与水印。正是这条口径抓到过两个「自读完全正常、
第三方读出 0 个字」的缺陷（PDF 的 `/W` 宽度数组被当名称写、嵌入字体的对象号没预留）。

## 环境要求

- **Node.js ≥ 22.19.0**（用到内置 `zlib.crc32` 与 `node:crypto`）
- **DSH ≥ 0.1.0-rc.6**（已在 0.1.6-alpha.2 实测装载与工具注册）
- 无第三方运行时依赖；不需要本机安装 Office（本地联动是可选能力）
